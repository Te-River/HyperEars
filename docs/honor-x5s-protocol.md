# Honor X5s Pro (BTV-ME10) Protocol Reference

## Device

| 项 | 值 |
| :--- | :--- |
| 零售名称 | 荣耀亲选耳机 X5s Pro |
| 型号 | BTV-ME10（`01 07` 信息帧显示 `BTV-ME10-00USFY`） |
| 形态 | TWS 入耳式 |
| Android Profile | A2DP / HFP / RFCOMM SPP / BLE |
| 厂商 App | 荣耀智慧空间（MagicHome） |

## Transport

- 私有控制通道：RFCOMM SPP（Channel 1），服务 UUID `00001101-0000-1000-8000-00805F9B34FB`（SDP 确认存在 Serial Port 服务）。
- 电池与模式控制均走该通道；BLE 通道由厂商 App 用于配置同步，首版不接入。

## Frame Format

所有帧以 `5A 00` 开头，第 3 字节为长度（**长度值 = 实际数据字节数 - 1**），随后为载荷与校验字节：

```
5A 00 <len> 00 <payload...> <crc...>
```

校验算法未逆向；字段值视为权威，校验不验证。

### 已知载荷

| 命令 | 帧（hex 载荷） | 方向 |
| :--- | :--- | :--- |
| 心跳 | `2B 79 01 00`（约每 3 秒） | 手机 ↔ 耳机 |
| 电量查询 | `01 08 01 00 02 00 03 00` | 手机 → 耳机 |
| 电量上报（推送） | `01 27 01 01 <盒> 02 03 <左> <右> <盒> 03 03 <左> <右> <充电标志> <crc>` | 耳机 → 手机 |
| 电量响应 | `01 08 01 01 <盒> 02 03 <左> <右> <盒> 03 03 <左> <右> <充电标志> <crc>` | 耳机 → 手机 |
| 模式命令 | `2B 04 01 02 <模式> <深度> <crc>` | 手机 → 耳机 |
| 模式状态回传 | `2B 2A 01 02 <x> <y> <crc>` | 耳机 → 手机 |

### 电量字段

- 左/右/盒为单个字节，直接十进制读取（`0x54` = 84%）。
- **0% = 该组件未连接**（如单耳佩戴时另一耳在盒内）。
- 末尾标志字节：`0x01` = 充电盒充电中，`0x00` = 未充电。
- `02 03` / `03 03` 组为左右耳字段组（02 组为电量，03 组为固定数据，非电量）。

### 模式字段

| 模式 | 命令模式字节 | 深度字节 |
| :--- | :--- | :--- |
| 降噪（ANC） | `01` | `00`=深度、`01`=智能、`02`=轻度、`03`=中度 |
| 透传 | `02` | `00` |
| 关闭 | `00` | `00` |

降噪命令统一发送"智能"档（`01 01`），不覆盖用户在厂商 App 中选择的深度。

### 状态回传编码（`2B 2A 01 02 <x> <y>`）

双耳佩戴：

| (x, y) | 含义 |
| :--- | :--- |
| `(01, 01)` | 降噪（智能） |
| `(01, 02)` | 降噪（轻度） |
| `(01, 03)` | 降噪（中度） |
| `(01, 00)` / `(00, 01)` | 降噪（深度档） |
| `(00, 02)` | 透传 |
| `(00, 00)` | 关闭 |

单耳佩戴（另一耳在盒内，编码简化、深度不上报）：

| (x, y) | 含义 |
| :--- | :--- |
| `(01, 00)` | 关闭 |
| `(01, 01)` / `(00, 01)` | 降噪 |
| `(00, 02)` | 透传 |
| `(00, 00)` | 关闭 |

单耳判定：电量帧中左或右为 0%（未连接）。

## Capability Confirmation

首版遵循"标准能力起步、有效响应确认"流程：

1. Adapter 初始保持标准能力：系统整机电量（`SYSTEM_AGGREGATE`）、媒体流转、原生 MiLink 三态卡片。
2. 私有通道连接后进入 `PROTOCOL_HANDSHAKE`。
3. 收到结构完整、字段合法的电量帧 → 开放私有组件电量，电池来源切换为 `PRIVATE_PROTOCOL`。
4. 收到结构完整、字段合法的模式状态帧 → 开放降噪、关闭、通透模式。
5. 模式写入由耳机状态回传确认（`DEVICE_REPORT`）。
6. 私有通道在有限次数内未获得有效协议响应时，关闭通道并保持标准耳机回退。

## Verified on device

- 三态切换（降噪/透传/关闭）经 SPP 通道真机验证。
- 组件电量（左/右/盒）查询与主动上报验证；充电盒充电标志验证。
- 单耳状态编码验证（关闭不误判为降噪）。
- HFP 标准 IPHONEACCEV 由系统解析为整机电量（系统路径，非本适配注入）。

## Not yet verified

- CRC 算法。
- 左右耳充电状态的独立标志（协议可能不回传，03 组固定）。
- 深度档切换的厂商 App 语义（首版固定智能档）。
- 其他荣耀型号的协议一致性（家族候选待多型号证据后引入）。

## Evidence Collection

- 协议帧来自 btsnoop HCI 日志（厂商 App 连接操作），多份日志交叉验证字节稳定。
- 帧格式、字段与厂商 App 电量页显示对照确认。
